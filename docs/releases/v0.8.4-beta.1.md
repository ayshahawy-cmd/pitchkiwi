# PitchKiwi 0.8.4 — free, notarized Mac download

Download PitchKiwi for free. It is open source under MIT, runs speech recognition locally, and needs no signup, subscription, account, API key, or payment.

## Mac downloads

- **PitchKiwi-macOS.dmg** — recommended installer for Apple Silicon Macs (M1+), macOS 14 or later. Includes the complete app and English model.
- **PitchKiwi-macOS.zip** — alternative archive with the same app.
- **.sha256 files** — matching checksums for both formats.

The official app and DMG are **Developer ID signed, notarized by Apple, and stapled**. Older 0.8.3 downloads and ordinary source/CI builds have a different signing status.

## Install

1. Download the DMG and optionally verify it with `shasum -a 256 -c PitchKiwi-macOS.dmg.sha256` from the folder containing both files.
2. Open the DMG and drag PitchKiwi.app onto the Applications shortcut.
3. Eject the disk image, open PitchKiwi from Applications, and confirm the normal macOS first-launch prompt.
4. Grant Microphone and Accessibility in onboarding.
5. Click a text field, hold Fn and speak, then release. Double-press Fn for hands-free capture and press again to finish; Escape cancels.
