# PitchKiwi 0.8.3 — open-source community beta

PitchKiwi is now available as MIT-licensed source with a downloadable Mac app. Hold Fn, speak, and release to insert local speech-to-text into an editor or coding-agent chat. Agent Prompt mode organizes explicit spoken cues and optionally adds fixed local execution guidance.

## Download and install

- **Requirements:** Apple Silicon (M1+), macOS 14+, Microphone and Accessibility access. English-first recognition.
- Download **PitchKiwi-macOS.zip** below. It includes the default local English model and all license notices.
- Download the matching **PitchKiwi-macOS.zip.sha256** and run `shasum -a 256 -c PitchKiwi-macOS.zip.sha256` from the folder containing both files.
- Unzip, move PitchKiwi.app to Applications, and open it. This beta is **ad-hoc signed and not notarized**. After trying to launch, use System Settings → Privacy & Security → Open Anyway if macOS blocks it. Follow [Apple's instructions](https://support.apple.com/en-ca/102445).
- Complete onboarding, click a text field, hold Fn and speak, then release. Double-press Fn for hands-free capture; press again to finish. Escape cancels. PitchKiwi does not press Return or submit the result.

Downloads require no signup, email, API key, or payment. The GitHub-generated Source code archives are for building the app yourself, not installation.

## Verification and limitations

A fresh source setup downloaded and verified the native framework/model, built successfully, passed **40 Swift tests**, and packaged a verified arm64 application. Real-model inference succeeded with synthetic speech. Website checks passed **10 API tests** and **48 local-link checks**. Full evidence and manual testing limits are recorded in [release verification](https://github.com/ayshahawy-cmd/pitchkiwi/blob/v0.8.3-beta.1/docs/RELEASE_VERIFICATION.md).

This is a community beta, with manual updates and no live partial transcription. Fn is fixed, English decoding is the current path, and captures should stay below five minutes. Arbitrary imported models are not digest-authenticated. Full cross-app/clean-user/older-macOS and instrumented privacy validation remain pending. Review recognized text before sending or executing it.

[Report a bug](https://github.com/ayshahawy-cmd/pitchkiwi/issues/new/choose) using synthetic content. [Report a vulnerability privately](https://github.com/ayshahawy-cmd/pitchkiwi/security/advisories/new).
