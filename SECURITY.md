# Security policy

Horme Flow is pre-release and does not yet have a private vulnerability-reporting address. Before public beta, maintainers must enable GitHub Private Vulnerability Reporting or publish a dedicated security contact and supported-version table.

Until then, do not submit real recordings, transcripts, clipboard contents, local context, credentials, or private project data in an issue. Use a synthetic reproduction and describe the affected component. If a report cannot be safely reduced to synthetic data, wait for the private reporting channel rather than disclosing it publicly.

The current threat model and privacy requirements are in [docs/SECURITY.md](docs/SECURITY.md).
